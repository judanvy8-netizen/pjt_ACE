# ACE 개선판 구현 및 확인 기록

기준은 ACE 웹서비스 개선 작업계획서 v4와 사진별 비교·품종 판정 추가 검토다.

| 범위 | 반영 내용 |
| --- | --- |
| P0 | 제출 자료·원본 해시 보존, 공통 640px 검출 입력, 표준 좌표, 웹 회차·세 CLI 검증 도구 |
| P1 | AiClient 분리, Controller의 저장소 의존 제거, CSV 검수 역할을 review로 분리, Java·Python 테스트 추가 |
| P2 | 빈 MySQL DB용 Flyway V1, 부호 오차, CSV 품종 파싱·정답 버전 저장, 공통 Verdict |
| P3 | 평가 일괄 조회와 상태 집계, 진행 중 텍스트 갱신, AI 이미지 오류 422·모델 오류 503·추론 오류 500 |
| P4 | 사진별 마릿수·품종 판정, MAE·분포·악화 수, 홀드아웃 정답 등록 경로 |
| P5 | 요청 전 AI 상태 확인, 연결 중단 시 대기 유지, 실패 일괄 재시도, IntelliJ와 PowerShell 실행 안내 |

품종 평가에 문서의 두 동의어를 적용했다. 종 혼동은 마릿수에서 추론한 의심 유형으로 표시한다. 품종 위치 판단은 정답 박스가 확보된 후 진행한다. 모델 라벨·번역 근거가 없는 견종은 미지원으로 단정하지 않으며, 지원 품종 분모가 불확실하면 전체 비율과 매핑 확인 상태를 보여준다.

## 검증 결과와 남은 항목

- 보관 CSV에서 40장·정답 개체 50마리, 마릿수 28/28/31, main-2 품종 27/50을 Java 계산으로 대조했다.
- Java 문법 및 비교 컴포넌트, Python 문법, JavaScript 구문을 확인했다. 대체 코덱·AI 엔진과 FastAPI 테스트 클라이언트로 640px 출력, 저장 결과 재사용, 409·422·503 구분을 확인했다. 정의서 61개 컬럼과 외래키 9개를 V1과 대조했다. 이 환경의 Gradle 배포 파일 다운로드가 실패해 전체 Gradle 테스트, Spring·MySQL 통합 실행과 실제 모델 120건은 현장 확인이 필요하다.
- 실측 골든은 미확정 상태다. README의 40장 회차 두 번을 실행하고 비교해 확정한다. 화면 응답 시간과 JDBC 쿼리 수는 그때 기록한다.
- 신규 홀드아웃 원본과 정답, 전체 ImageNet 견종 매핑, IntelliJ가 생성한 실행 구성 파일은 포함되지 않았다. 검증 방법과 파일 위치는 README에 있다. 선택 작업인 정답 박스와 ablation은 보류했다.
