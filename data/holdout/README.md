# 홀드아웃 사진 평가

튜닝에 쓰지 않은 사진 20장 이상을 모아 images 폴더에 hold_001.jpg 형식으로 저장합니다. 개·고양이 단독, 혼재, 여러 마리, 가림, 작은 개체를 포함합니다. data/ground_truth.csv와 같은 열의 ground_truth.csv를 이 폴더에 작성합니다. 파일명과 내용은 기준 40장과 달라야 합니다. 사진 출처, 사용 조건, 촬영 조건, 정답 작성자를 정리합니다.

웹에서 홀드아웃 사진을 등록하고 회차를 실행한 뒤 CSV 정답을 검수합니다. 홀드아웃 결과를 보고 규칙을 바꿨다면 해당 사진은 튜닝 자료로 옮깁니다. 제공된 프로젝트에는 신규 홀드아웃 사진과 정답이 들어 있지 않습니다.
