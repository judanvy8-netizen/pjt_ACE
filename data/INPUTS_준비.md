# 데이터 준비 — 05. 반려동물 사진 탐지기

이 프로젝트에는 출처와 라이선스를 확인한 JPG 사진 40장을 `data/images`에 넣었습니다.

- 필요 자료: `data/images`에 있는 사진 40장
- 사진 구성: 개 한 마리 11장 / 고양이 한 마리 12장 / 개 두 마리 6장 /
  고양이 두 마리 3장 / 개와 고양이 각 한 마리 3장 / 개 세 마리 1장 /
  개·고양이 외 다른 동물 4장
- 파일 이름 규칙: `img_001.jpg`~`img_040.jpg` (이번 버전에서는 영상 파일을 사용하지
  않습니다.)
- 사진별 출처와 원본 페이지는 `data/촬영계획_40건.csv`에 적었습니다.
- 사진에 보이는 개·고양이 수와 출처에서 확인한 품종은 `data/ground_truth.csv`에
  적었습니다. 여러 마리는 사진 속 위치를 함께 확인하세요.
- `data/images` 폴더가 없으면 `FileNotFoundError`가 나옵니다. 먼저 폴더와 사진 40장이
  있는지 확인하세요.
