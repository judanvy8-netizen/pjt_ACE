# 데이터 준비 — 05. 반려동물 사진 탐지기

이 프로젝트에는 출처와 라이선스를 확인한 JPG 사진 20장을 `data/images`에 넣었습니다.

- 필요 자료: `data/images`에 있는 사진 20장
- 사진 구성: 개 한 마리 4장 / 고양이 한 마리 4장 / 개와 고양이 함께 4장 / 여러 마리
  2장 / 다른 동물 4장 / 개와 고양이 여러 마리 2장
- 파일 이름 규칙: `img_001.jpg`~`img_020.jpg` (이번 버전에서는 영상 파일을 사용하지
  않습니다.)
- 사진을 가져온 곳은 `data/촬영계획_20건.csv`의 출처 칸에 간단히 적었습니다.
- 정답표의 값은 **추측해서 작성하지 말고 사진을 사람이 직접 확인하고**
  `data/ground_truth.csv`에 입력하세요.
- `data/images` 폴더가 없으면 `FileNotFoundError`가 나옵니다. 먼저 폴더와 사진 20장이
  있는지 확인하세요.
