이 데이터셋의 분석을 실행하고 결과를 확인하세요.

  1. 등록한 사진 확인

    등록한 사진을 펼쳐 분석할 사진을 확인하세요.

  2. 분석 시작

    분석 시작을 누르면 main, main-1, main-2, main-3가 실행됩니다. 사진 40장은 한 회차에 총 160건입니다.

  3. 진행 상태 확인

    분석 회차의 성공·실패 건수를 확인하세요. 실패한 항목은 다시 시도할 수 있습니다.

  4. 결과 비교 및 검수

    사진별 결과에서 사진명을 눌러 원본과 네 버전 결과를 비교하세요. CSV 정답이 있으면 비교 후 검수 저장을 누르세요.
