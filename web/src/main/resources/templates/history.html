    분석 이력 작업 안내

    1. 요약과 필터 확인

      마릿수 일치율과 평균 절대오차를 확인하세요. 오답만 보기에는 마릿수 또는 품종 오답이 표시됩니다.

    2. 사진 결과 비교

      사진명을 누르면 같은 회차의 원본과 해당 회차의 모델 결과가 열립니다.

    3. 정답 확인 후 검수 저장

      CSV 정답과 결과를 비교한 뒤 검수 저장을 누르세요. 목록에서 검수완료 상태를 확인할 수 있습니다.

    4. 실패 기록 삭제

      실패만 보기에서 기록을 선택한 뒤 사진명과 모델, 삭제 건수를 확인하세요.

    평가 결과와 검수 상태

    평가 결과 열은 실행 상태 또는 마릿수 비교를 표시합니다. 검수 상태는 사람이 확인하고 저장했는지 보여줍니다.
